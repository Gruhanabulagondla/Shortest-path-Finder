# Shortest Path Finder 🗺️

A Python-based Shortest Path Finder that uses the Breadth-First Search (BFS) algorithm to find the shortest route between locations.

## Features

- Represents locations using a graph
- Finds shortest path between two locations
- Uses BFS algorithm
- Displays the path
- Displays number of steps
- Handles invalid locations

## Technologies Used

- Python
- BFS
- Graphs
- Queue
- Sets
- Dictionaries

## How to Run

python shortest_path_finder.py
